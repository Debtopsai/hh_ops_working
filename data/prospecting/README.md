# Prospecting data

Working area for the cold-email master list. Plan and schema:
[`docs/PROSPECT_LIST_BUILD.md`](../../docs/PROSPECT_LIST_BUILD.md).

```
raw/            Vendor + scraper exports, untouched. GITIGNORED (large, PII-heavy,
                re-downloadable). Keep the purchased list and Databar dumps here.
staged/         Per-source normalised CSVs in the canonical schema. Tracked.
suppression.csv Generated — do not hand-edit. See below.
master.csv      Generated by identity resolution (not yet built).
```

## Regenerating suppression

```bash
python3 scripts/build_suppression.py              # rebuild from customers.csv
python3 scripts/build_suppression.py --check "info@somecafe.co.nz"
```

`--check` accepts an email, phone or business name and reports any match. Run it
before adding a prospect by hand.

Rebuild whenever `data/customers.csv` changes — a new customer who keeps
receiving cold outreach is the most visible failure mode of this pipeline.
