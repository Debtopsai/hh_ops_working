# HireHospo reel caption — output template

Produce all four blocks below. Never use em dashes anywhere.

## 1. Transcript (on-screen text)
State clearly this is the on-screen text read from the video (audio is not
transcribable in this environment). Give the joined-up script as one quoted line,
then the beat-by-beat sequence if useful. Note the video length, aspect ratio, any
real catalogue equipment visible, and the end card.

## 2. Primary caption (recommended)
Structure:
- **Hook line** (echo or sharpen the video's opening on-screen line). One emoji max.
- **Body** (2 to 3 short lines): the offer in brand voice. Use the approved phrases:
  "low weekly payments", "minimal upfront cost", "pays for itself from day one",
  "keep your cash working". Say "kitchen equipment", never "gear".
- **CTA line:** "Comment BROCHURE and we'll send you our latest stock list. 👇"
- **Microcopy line:** *Subject to credit approval.*
- **Hashtag block** (8 to 12): mix brand, category, and Auckland/NZ hospo tags.

## 3. Shorter alt caption
A punchier version that keeps the hook, one body line, the Comment BROCHURE CTA, the
microcopy, and a trimmed hashtag set (5 to 6 tags).

## 4. Notes
- Flag any figure decisions: "+GST" attaches only to prices HireHospo quotes
  (e.g. $4.66/day +GST), never to rhetorical figures (e.g. "a $50,000 oven").
- Remind that "Comment BROCHURE" only works if the Meta/ManyChat auto-reply is set
  up to DM the stock-list link. Offer to write that auto-DM message.
- Ranges use "1 to 2 days" if the user wants no dashes at all; otherwise an en dash
  "1–2 days" is acceptable for a numeric range (it is not an em dash).
