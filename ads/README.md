## The two formats

The **15s house-format scripts are the ones to produce.** They match how HireHospo ads are actually made: real kitchen footage, two-line text lockups in white and gold, a music bed with **no voiceover**, and a "Get Stock List" CTA.

The **30s scripts were written before `Video_01_revision.mp4` was available.** They assume a voiceover, a dark motion-graphics look, and an "Apply now" CTA — all drawn from the ad-factory skill's *provisional* visual system, which that file says a real brand asset supersedes. `Video_01` is that real asset. Keep the 30s scripts for their strategy and catalogue research, and for a longer VO-led cut if one is ever wanted, but don't build them as-is.

## Standing issues across all creative

1. **Four different daily rates are in circulation** — $4.66 (brand reference), $3.99 and $6.99 (live ad names), $14.99 (`Video_01`). One offer, four numbers. Needs one owner and one answer.
2. **The live video carries no "+ GST" and no "Subject to credit approval."** Both are added to the new scripts as an end-card footnote strip.
3. **Washpro is never named in the live video** despite doing the delivery, install and service. Both new scripts attribute it correctly.
4. **The product feed marks every item `condition: "new"`** while brand guidance says most stock is refurbished-with-warranty. Both new scripts claim only "with warranty", which is safe under either reading — but the feed and the guidance still need reconciling.
